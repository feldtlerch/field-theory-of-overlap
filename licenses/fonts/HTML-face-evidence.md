# HTML font-face evidence

The two documents use the same English text setup in `documents/paper/main.tex`, `documents/paper/main_explainer.tex.in`, `documents/paper-build/templates.toml` and `documents/paper-build/runtime.toml`. The table identifies pinned prose and monospace faces and possible KaTeX mathematics faces, not a settled HTML mathematics font choice; exact mathematical face use awaits a rendered glyph inventory. Small capitals are a requested presentation of the prose family, not a separately pinned face; its glyph support and appearance remain to be observed.

`LICENSING.md` supplies the project's reading of the distribution terms and requires every embedded file to decode byte-identically to its pinned input, with no subsetting, conversion or renaming, and every document copy to carry the named licence texts and own notice. “Yes” below means yes under that reading for the whole-file route, not an independent permission ruling or a subset in the planned package. The mathematics rows identify pinned WOFF2 variants without choosing a delivery font; the same twenty faces also have pinned TTF and WOFF variants and their own notices, but a given document need only carry the variants it embeds. The TeX bundle pins are in `tools/assembly/native-lock.toml` for Inconsolata at lines 22653–22654 and Pagella at 113116–113120; KaTeX font hashes are in `tools/notation/support-digests.json:191-427`.

Subsetting is a modification permitted conditionally by the applicable licences: GUST/LPPL requires its modified-work distribution conditions and complete-work information; OFL requires its licence and copyright notice and forbids a Modified Version from using a Reserved Font Name without permission; Apache permits modified distribution with its licence, retained notices and a prominent notice stating that a modified file was changed (section 4(b)). The Inconsolata OpenType files have the multiple licence readings described in `LICENSING.md`, so a subset would need to meet each applicable reading. No subset is admitted by the current byte-identical HTML delivery condition.

The typeset documents also name `texgyrepagella-math.otf` through `unicode-math` (`documents/paper/main.tex:15`, `documents/paper/main_explainer.tex.in:15`), and its bytes are pinned at `tools/assembly/native-lock.toml:113119`. No matching per-file notice or licence evidence for that file is retained here, so it may not be embedded in HTML until licence evidence is retained. The retained KaTeX notices do not establish its permission. The source tree contains licence records but not the font binaries; generation reads the pinned support bundle and checks byte identity before embedding.

The generated English excerpt HTML files embed the complete pinned `texgyrepagella-regular.otf`, `texgyrepagella-italic.otf` and `texgyrepagella-bold.otf` files for paragraph, refrain and heading text respectively. The writer checks each file against a digest copied from `tools/assembly/native-lock.toml`; the HTML includes the four Pagella licence and distribution texts and each embedded file's own notice. The stylesheet gives the embedded Pagella family first priority and names a generic serif fallback for an environment that cannot use it. These excerpts contain no mathematics or monospace mention, so no mathematics or monospace face is embedded.
