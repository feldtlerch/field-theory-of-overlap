# Licensing · `rem:ftoo:licensing`

The repository licenses code and documents separately. `LICENSE-CODE` is the MIT No Attribution license (MIT-0) and covers the crates and tooling; `LICENSE-DOCS` is the CC0 1.0 Universal public-domain dedication and covers the paper, its explainers and the decision records. Both are maximally permissive by choice: the work's value is in being read, used and checked, and attribution is welcome but never owed. The calculation engine this project depends on publishes under CC0 as well.

The committed PDFs embed font programs that remain under their own licences (the GUST Font License, the SIL Open Font License and the Apache License 2.0); the CC0 dedication covers the paper's and the explainer's own content, not those fonts.

The retained licence evidence covers sixty-six font files for HTML rendering: four prose, two monospace and sixty mathematics files, named below. These files are published for typesetting, where embedding a font in the document it sets is the ordinary intended use, and the published PDFs already embed the prose and monospace fonts, as subsets the typesetting engine selects. An HTML rendering may embed whole files instead on two conditions: the embedded data decodes to bytes identical to the corresponding pinned font input, with no subsetting, format conversion or renaming, and every copy of the document carries the licence texts and notices listed for that file below, from `licenses/fonts/`. This project reads each file's terms as permitting embedding on those conditions, for the reasons given per group below. Markdown carries no fonts.

The prose files `texgyrepagella-regular.otf`, `texgyrepagella-italic.otf`, `texgyrepagella-bold.otf` and `texgyrepagella-bolditalic.otf` are TeX Gyre Pagella 2.501 under the GUST Font License, which provides that the work "may be distributed and/or modified under the conditions of the LaTeX Project Public License, either version 1.3c of this license or (at your option) any later version". The LPPL 1.3c considers "Distribution of only part of the Work" a modification (clause 2), so embedding four of the Work's files is distribution under its clause 6, which among other conditions requires "Information that is sufficient to obtain a complete, unmodified copy of the Work" (clause 6d); the retained README supplies it by naming the release's download page and the manifest that lists the Work's files. Each copy of the document therefore carries `GUST-FONT-LICENSE.txt`, `LPPL-1.3c.txt`, `README-TeX-Gyre-Pagella.txt`, `MANIFEST-TeX-Gyre-Pagella.txt` and the file's own notice. The GUST Font License also asks that derived works rename the fonts and the files listed in the manifest, which it marks "requested, but not legally required"; the embedded files keep their names so that they stay identical to the release.

The monospace files `Inconsolatazi4-Regular.otf` and `Inconsolatazi4-Bold.otf` are version 1.015 from the Inconsolata 1.121 distribution. Their own name tables differ: Regular's notice ends "Licensed under SIL font license.", while Bold's states "Released under the Apache 2 license." and carries the Apache License 2.0 header. The distribution's README states the SIL and Apache licences for its PostScript files ("so is the derived font Inconsolatazi4-Regular.pfb"; "so therefore is the derived font Inconsolatazi4-Bold.pfb") and names neither OpenType file, and the distribution carries the OFL text but no Apache text, so the terms of each OpenType file admit more than one reading. The README also places "the other files in the archive Inconsolata.zip" under LPPL 1.3 or any later version; its scope for the OpenType files is ambiguous. Each copy of the document therefore carries, for both files, `OFL-1.1.txt`, `OFL-Inconsolata.txt` (the OFL as distributed, with the distribution's copyright heading), `Apache-2.0.txt`, `LPPL-1.3c.txt`, `README-Inconsolata.txt` and the file's own notice. That meets the OFL's condition that "each copy contains the above copyright notice and this license" and the Apache License's conditions to "give any other recipients of the Work or Derivative Works a copy of this License" (section 4a) and to retain "all copyright, patent, trademark, and attribution notices" (section 4c), with the LPPL text also retained for the README's third reading; the Apache text does not displace Regular's own SIL notice.

The sixty mathematics files are the `.ttf`, `.woff` and `.woff2` files for `KaTeX_AMS-Regular`, `KaTeX_Caligraphic-Bold`, `KaTeX_Caligraphic-Regular`, `KaTeX_Fraktur-Bold`, `KaTeX_Fraktur-Regular`, `KaTeX_Main-Bold`, `KaTeX_Main-BoldItalic`, `KaTeX_Main-Italic`, `KaTeX_Main-Regular`, `KaTeX_Math-BoldItalic`, `KaTeX_Math-Italic`, `KaTeX_SansSerif-Bold`, `KaTeX_SansSerif-Italic`, `KaTeX_SansSerif-Regular`, `KaTeX_Script-Regular`, `KaTeX_Size1-Regular`, `KaTeX_Size2-Regular`, `KaTeX_Size3-Regular`, `KaTeX_Size4-Regular` and `KaTeX_Typewriter-Regular` in the locked KaTeX 0.19.1 package. Each file's name table states "This Font Software is licensed under the SIL Open Font License, Version 1.1." and names its family's Reserved Font Name, such as `KaTeX_Main`. The OFL grants permission "to use, study, copy, merge, embed, modify, redistribute, and sell modified and unmodified copies of the Font Software" subject to conditions that include "each copy contains the above copyright notice and this license" (condition 2) and that no Modified Version uses a Reserved Font Name without permission (condition 3), so each copy of the document carries `OFL-1.1.txt` and the file's own notice. The OFL counts a change of format as a Modified Version: choosing among the three formats the package ships modifies nothing, whereas converting or subsetting a file would. The OFL's requirement to stay under the OFL "does not apply to any document created using the Font Software", and KaTeX's software is licensed separately under MIT, which does not cover the fonts.

`OFL-1.1.txt` is the SPDX License List's text of the OFL 1.1 (license-list-data v3.26.0); `OFL-Inconsolata.txt` is the OFL as distributed with Inconsolata. Apart from the latter's copyright heading they differ only in layout (line wrapping, blank lines and dashed rules around the title) and in two em dashes in the definition of Modified Version where the Inconsolata copy has double hyphens. Copyright statements and Reserved Font Names come from each font's own name table, never from another font's licence heading.

`licenses/fonts/notices/` holds one notice per font file, named after the file with `.txt` appended; each reproduces entries of that file's own name table, headed by their name-table IDs. The texts and notices come from GUST, the TeX Live historic archive at Utah, the npm registry, the Apache Software Foundation and the SPDX License List repository on GitHub.
