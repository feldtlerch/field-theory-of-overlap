# Licensing · `rem:ftoo:licensing`

The repository licenses code and documents separately. `LICENSE-CODE` is the MIT No Attribution license (MIT-0) and covers the crates and tooling; `LICENSE-DOCS` is the CC0 1.0 Universal public-domain dedication and covers the paper, its explainers and the decision records. Both are maximally permissive by choice: the work's value is in being read, used and checked, and attribution is welcome but never owed. The calculation engine this project depends on publishes under CC0 as well.
