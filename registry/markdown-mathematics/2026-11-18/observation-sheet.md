# Math probe observation sheet

Baseline: c8c98f7. This sheet is blank evidence collection, not an acceptance or compatibility claim. View the repository's file pages on the forge's experiment branch; local preview and raw-file views are not substitutes. Do not correct candidate bytes while recording results.

Record once: observer; UTC date/time; forge URL and candidate commit; browser/version; signed-in state; theme; viewport width/height; any visible math-engine/version information (otherwise unknown). Keep a screenshot reference for each file and for failures. Repeat the long-line cases at 400-pixel width and record the actual width. Record other mobile/app clients only if actually viewed.

For each row fill T (typeset), S (source), E (error), or mixed; record A and B separately where supplied, and every formula if one case has several. For S/mixed copy the displayed text exactly, naming missing or changed underscores, braces, backslashes, stars, brackets, pipes, tildes, carets or dollar/backtick delimiters; note accidental emphasis or broken table/list structure. For E copy the exact visible error text and distinguish page text from browser-console text if a console was inspected; write none or not inspected instead of guessing. Typeset-but-wrong is not success: record lost scripts, wrong characters, missing pending labels, numbers or rows. Do not paste unrelated console data.

M01–M06 seek the same mathematical appearance through different wrappers; escaped underscores count as a failure if they become literal underscores. M29/M35 test automatic numbering and record presence/absence without assuming it. Negative controls M48–M50 intentionally fail; M51 detects whether failure damages later rendering. Equations are invented formulas or the main document's example.
