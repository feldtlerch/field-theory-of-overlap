# ADR 021: Reader characters in unit prose · `rec:adr:021-unit-prose-typography`

**Decision (Statement)** · `dec:units:reader-character-typography` — Unit prose is authored once per language using the reader's characters. Each renderer owns their target spellings; TeX input conventions are rendering spellings, not a second prose authoring language. Emission and recovery compare decoded characters, preserving words, punctuation and spacing intent. A mapping that merges distinct source characters into a different rendered character is refused at its source location. This amends ADR 005's Decision clause “one authored text per language, from which the LaTeX and Markdown documents are both generated” by specifying the prose character representation and the ownership of its target spellings (`rec:adr:005-statement-units`). Mathematics retains ADR 004's notation contract (`rec:adr:004-notation-ast`); differences a medium cannot express require an explicit presentation decision under ADR 017 (`rec:adr:017-screen-rendering-contracts`).

**Reasons (Why)** · `arg:units:typography-reasons` — Reader characters state which punctuation the author means independently of a typesetter's input conventions. One source with derived target spellings prevents a screen copy and a typeset copy from drifting. Decoded-character recovery checks that the intended characters survive emission, while byte gates check the concrete artifacts. Explicit spacing intent avoids substituting sentence spacing, word spacing or nonbreaking spacing for one another.

**Declined (Alternatives)** · `arg:units:typography-declined` — TeX prose with screen-side translation makes one renderer's syntax the prose language and requires the other renderers to interpret it. Contextual smartening guesses punctuation the author can state directly. Separately authored target text creates a second authority. Unconditional Unicode pass-through assumes every target preserves the same characters and ligatures. Each alternative weakens the connection between the authored characters and what readers receive.

**Consequences (Accepted)** · `arg:units:typography-consequences` — Conversion makes character choices explicit and pays for reviewed target mappings and their recovery. The admitted repertoire and its migration are extended by reviewed implementation steps; this record does not claim that every character or style already has a mapping. Styles' authoring syntax is not decided here. ADR 005's per-target display bodies remain unchanged; their prose regions use the same typography mappings. Existing artifact byte gates, ADR 016's source and acceptance obligations, and ADR 017's two Markdown roles and independent presentation review remain in force. A representation change must account for existing artifact bytes rather than treating visual similarity as byte equality. Adjacent apostrophes are the merging spellings refused by the current prose admission; until the admitted repertoire narrows, TeX emission and recovery read a straight prose apostrophe as curved, so it stays straight on screen and prints curved in type.
