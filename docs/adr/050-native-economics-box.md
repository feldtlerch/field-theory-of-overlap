# ADR 050: Native economics boxes · `rec:adr:050-native-economics-box`

**Decision (Statement)** · `dec:documents:native-econ`

An economics box is a shared prose unit with a typed econ role, not an opaque TeX display. The unit owns one body per required language, a title and stopping statement per required language, an existing canonical paper target, a referenced paper object, ordered bibliography keys and exactly one declared departure. Its target selector places one `documentary-targets` paper mint in the generated environment's label option under M041 and M043; this is the same paper-origin mint route as a visible auxiliary handle, with a different checked placement, and it admits no theory object or permanent tag. The first form is English prose with one parenthetical bibliography insertion. New body forms enter only with checked consumers.

The paper fragment calls the inherited econ environment with generated arguments. It preserves the environment's counter increment, title reference, target mint, departure validation, concordance row and footer. It does not introduce a grade-audit scope: the inherited subsection audit remains its owner. The one metadata source supplies both the generated options and the expected row, whose five fields are departure, tag, onref, cites and stopsat. The title is separate and must agree, after bounded decoding, with the inherited heading declaration reached through the target's checked binding. The inherited concordance prints four field values in three columns: departure, own handle, and citation plus stopping text in the third column. The fifth stored field, onref, has no printed cell; its evidence is the bound five-argument capture, option recovery and referenced identity in the box header. An argument capture does not establish that the four rendered field values, their column membership or the drawn row are correct.

The shared plan owns the box number, title, ordered body and footer identities and public destination. While the surrounding structure is inherited, a bounded source-context reader derives the economics number; its carrier to the paper check is the emitted annotated Markdown header, not a new number artifact. Each paper pair compares that number with its own typesetter output and destination evidence. No unit authors its number and no auxiliary file feeds generation. Screens retain the header's referenced object as a plain unlinked handle, with its target in annotated Markdown, following ADR 037's prose treatment. The PDF keeps its inherited located reference unchanged: the measured header reads (on OP:VMORAL (Def. 11.2)), with only Def. 11.2 linked to the referenced definition. Its own footer handle is not a link; the departure footer handle links to the departure's first concordance row, not necessarily this box's row. The screen choice avoids a second theorem-counter reader and preserves reference identity without claiming a screen locator that the plan has not derived. The first box uses the inherited paper profile, a header-less one-cell HTML table in forge Markdown and a semantic HTML section with existing embedded prose faces. The Markdown table has real paragraph elements, no header row and no presentation-role attribute. The forge strips that attribute and exposes the element as a table; no screen-reader behavior or accessibility conformance is claimed. The project's HTML uses a section, not a layout table.

The same Python-checked bridge supplies the pinned derived bibliography bytes as well as bindings, departure evidence and native-target evidence. Bibliography derivation remains owned by bibroute; Rust does not repeat its substitutions or its expected digest. The one-book exception admits the parenthetical citation of a:sencapability only after exact stock/derived row comparison and independent printed-label evidence. All other changed entries remain refused. Native textual citation of that book remains refused until it has a consumer; the concordance's textual citation is inherited PDF evidence here. Screen References text follows the existing author-comma-year style, with the book's title, address and publisher derived from fields, rather than copying a measured PDF string as an authority.

Only the declared targets of the first consumer are admitted: paper fragment, Markdown and HTML. A standalone LaTeX econ target refuses until its compared support closure has a consumer. The paper continues to load its inherited support directly, as ADR 041 requires; this consumer neither loads a second copy nor creates a checking shim. It changes no mathematical notation profile.

**Reasons (Why)** · `arg:documents:native-econ-reasons`

Document preparation already invokes the Python authority through CheckedPaperLookup::check (documents.rs:443; documents/registry.rs:164–205). Extending that captured bridge with in-memory bibliography derivation preserves one boundary. It does not require an additional process, a committed derived bibliography or another record. The same record governs the book exception and the box that consumes it.

The six options at the source are executable inputs as well as descriptive text. Flattening them into a paragraph loses the label, numbering, classification validation and derived row. Repeating them in a table file creates two authorities. Keeping them as typed fields lets preparation and recovery compare what each consumer actually receives. A single string for departure expresses the inherited one-departure condition directly; resolution against the inherited roster retains its meaning without requiring theory admission before the native-renderings boundary.

The excerpt already selects fragment, Markdown and HTML (`units/documents.toml:7–10`). Its PDF is the paper's PDF, whose preamble already loads the environment. Extending standalone native support ahead of such a consumer would add package and identity machinery without closing this scope. A bounded source-derived counter context, checked against the produced pair, follows the existing appendix-reference bridge rather than inventing an authored number or a second typesetting pass as a source authority (`rec:adr:040-placeholder-index`).

**Declined (Alternatives)** · `arg:documents:native-econ-declined`

A generic raw-environment escape leaves recovery unable to distinguish title, body, classification and effects. Separate authored bodies per target are unnecessary for this prose and can disagree about what the box says. Keeping the old option block beside a native body leaves content in two sources. An independent concordance registry repeats the options. Treating econ as a theorem or adding an audit push/pop changes the inherited checking scope. Keeping a target key only in a source comment supplies a false mint witness. Using e:capability as the unit id violates M039's three-part unit-label grammar; the unit therefore has its own id and transfers the existing paper target as its second checked mint. Promoting the paper target to the permanent graph merely to render it pulls theory admission into the wrong release boundary.

The forge's quotation block is declined for the box: it reads as quoted text and dims the prose. Ordinary rules and an unframed block do not identify a box as clearly; a Markdown pipe table adds an empty header strip and replaces paragraphs with line breaks. A presentation role on the HTML table is declined because the observed forge strips it. The header-less HTML table preserves full-contrast text and real paragraphs at the observed widths, accepting the faint border and table semantics.

Hard-coded current numbers and auxiliary-derived generation both obscure their authority; the latter also introduces a cycle. Loading all overlap macros or all economics declarations into standalone native documents without a consumer adds unrelated support. Treating argument equality as rendered-cell equality omits a real failure mode. Treating the paragraph comparator or the unfinished batch gate as an econ acceptance check exceeds their admitted scope.

**Consequences (Accepted)** · `arg:documents:native-econ-consequences`

Typed econ admission requires a complete consumer: the whole environment, all six options, the paper target evidence, generated scope use, recovery, checking evidence and observed screens move together. Counter derivation lands with the econ header that carries its comparison evidence; it is not an earlier unused numbering layer. The first target is `e:capability`; its ordinary unit id remains a three-component label. The paper lookup remains the authority for canonical binding and printed spelling. Native target evidence is collected before resolving it; the unit's `documentary-targets` declaration is its one paper-mint origin, and no label-mint inventory row repeats that owner. Wrong case, alias-as-mint, a second owner, a retained authored definition or an unavailable target binding refuses. Referenced keys that the removed source merely mentioned keep evidence in a still-authored declared source.

The bounded counter reader checks the inherited definition and counts section and economics events in source order; recognised resets and indirect counter commands refuse. The annotated screen header carries the resulting number, which is compared with the producing paper pair's auxiliary counter, title and destination. The header-less Markdown table preserves the observed full-contrast text, paragraph breaks and narrow wrapping while retaining visible table semantics; the HTML section has its own semantic title, body and footer. Generated bytes and both screen structures are recovered against the plan, and independent appearance judgment remains governed by ADR 017:21 and ADR 024:5. The inherited PDF box and concordance retain the title, footer, located reference, five stored row fields and four printed field values in three columns; the unprinted onref field is checked by its option and header identity. Bound parent evidence places the box, definition, departure and concordance row at distinct destinations, without making any page a source constant. Pair-byte equality, when obtained, corroborates the printed ink and effects but does not replace screen recovery. An econ environment is outside the selected-paragraph scope of M077 and the plain-batch scope of M082.

The Sen book route accounts for the inherited bibliography derivation, the native parenthetical form, the inherited concordance's textual form, the screen References entry and independent printed-label evidence. Its admission carries the complete native box as its screen consumer; a book-only admission with no screen consumer is not retained. Generated coverage and registered development gaps remain truthful; neither this box nor a placeholder index establishes complete-document release.
