# ADR 030: Native renderings, complete graph and native model · `rec:adr:030-native-renderings-complete-graph-native-model`

**Decision (Statement)** · `dec:publication:version-boundaries`

The complete-document release gate is the boundary by release 0.6.0: every passage of the paper and of the explainer must be natively generated from one source for PDF, Markdown and HTML, and every rendered table must have a native body in each medium. No placeholder message for missing content satisfies this gate. The theory graph need not be full: native prose may belong only to the document structure, with no link into the theory graph; no step toward 0.6.0 requires admitting prose content into the theory graph. Inherited files other than passage and table bodies, including typesetting support and checking machinery with the declarations it reads, may remain after this gate but must be replaced by release 0.7.0; any passage or table body such a file produces must be native by release 0.6.0. The complete-graph boundary is the boundary by release 0.7.0: the full content and machinery of the earlier system must be present in the graph. The mathematics may be unverified, but it must be present, its links made, and the relationships the earlier system has must be checked. The machinery must be re-architected, not redesigned, so retirement of the earlier system becomes possible. The native-model boundary is the boundary by release 0.8.0: the mathematical and logical model must be re-conceived and built new, clean and native. Representation, relationship checking and mathematical certification are distinct.

**Reasons (Why)** · `arg:publication:version-boundaries-reasons`

Complete documents need not await a complete theory graph. Faithful representation with preserved relationships permits retirement without claiming mathematical certification. Re-conception is a different task from preserving a model. The earlier system is ADR 008's “earlier private implementation” (`dec:publication:fresh-history`); its content and machinery include the mathematics and its links, the relationships it checks, and the typesetting layer's checks described by ADR 014.

**Declined (Alternatives)** · `arg:publication:version-boundaries-declined`

Missing-content placeholders do not deliver complete documents. Requiring theory admission before native prose couples independent obligations. Redesign while representing the earlier model obscures preservation; universal certification as a condition of representation confuses representation with proof.

**Consequences (Accepted)** · `arg:publication:version-boundaries-consequences`

ADR 016:11 is replaced by: “The complete-document release gate requires every passage of the paper and explainer and every rendered table body to be native by release 0.6.0 (whose development version is set as `0.6.0-dev` in `documents/paper-build/templates.toml`), from one source for PDF, Markdown and HTML, with no placeholder message for missing content, no rendering corrected by hand and the reader rules holding in every rendering. Native prose may belong only to the document structure; no theory link or admission is required for this gate. Inherited files other than passage and table bodies, including typesetting support and checking machinery with the declarations it reads, may remain after this gate but must be replaced by release 0.7.0; any passage or table body such a file produces must be native by release 0.6.0. The full mathematical model beyond the present claim audit falls under the complete-graph and native-model boundaries of ADR 030. The PDF remains a rendering; HTML is one page per document, with an internal contents list and reciprocal links between the documents. Document completeness does not enlarge audit coverage, and every rendering states what is and is not audited (`rec:adr:002-status-and-coverage`). Detailed evidence obligations for the complete-graph and native-model boundaries are deferred to a later decision record.” This replaces “no authored source file covered by ADR 014's source authority survives that release”.

ADR 016:13's sentence “A rendering made before conversion is complete cannot satisfy the complete-document release gate.” becomes: “A rendering with any passage or table body not yet native cannot satisfy the complete-document release gate; inherited files other than passage and table bodies may remain until the complete-graph boundary, provided any passage or table body they produce is native.” ADR 017:15's sentence beginning “Where a part is not yet converted” becomes: “Where rendered content is not yet native, a screen rendering must show a placeholder message without a link; such a rendering cannot satisfy ADR 016's complete-document release gate for native passages and table bodies (`rec:adr:016-admission-and-native-documents`).” Its separate requirement for converted links remains.

ADR 014:7's final sentence, “The exception ends file by file, as each is replaced by generation from the theory graph or rewritten here.”, becomes: “The inherited-file exception ends for passage and table bodies at the complete-document release gate; inherited files other than those bodies, including typesetting support and checking machinery with the declarations it reads, may remain until the complete-graph boundary, provided any passage or table body they produce is native.” ADR 014:9 is replaced by: “The data tables are fixed data of this version: nothing in the repository regenerates them, and they are named `data` rather than `generated` because no generator owns them. By release 0.6.0 each fixed data table must have one native body for PDF, Markdown and HTML; the inherited typeset table must no longer be a rendering authority. By release 0.7.0 each fixed data table must be generated from the theory graph under the registered condition of `open:paper:fixed-data-tables`. An authored change to the data tables is reviewed as text and surfaced by the byte receipt and artifact gates.”

ADR 016:33's sentence beginning “Its bounded typesetting exception” becomes: “Its bounded typesetting exception ends for passage and table bodies at the complete-document release gate; other inherited files may remain until the complete-graph boundary, provided any passage or table body they produce is native; no new exception is admitted (`rec:adr:014-paper-pair`).” This record also bounds ADR 014:11 and ADR 016:35, :37 without removing their replacement conditions: the paper-scoped handle store, label-mint inventory evidence and M060's paper-inventory alternative must end by the complete-graph boundary, with their retained bindings, targets and checking obligations covered by their native replacements.

ADR 016:22's second sentence becomes: “The complete-document release gate, complete-graph boundary and native-model boundary permit complete documents before theory admission and a complete represented model before mathematical certification.” ADR 014:17 loses only the clause “, and re-implementing it before the graph can generate its tables would be a new renderer with visual-regression risk and no gain in checked content”; its first sentence consequently reads: “The typesetting layer is typesetting source under the documents licence, not program code; like everything this repository publishes it is subject to the publication audit (`rec:policy:publication-audit`), its executable strings and rendered output included.” Its second sentence, including “no new semantic checker or claim of checking coverage is added to it”, remains. ADR 014:21's first sentence becomes: “Releasing documents with missing passages or rendered table bodies is declined because readers would receive incomplete content.” Its third sentence becomes: “A second hand-maintained copy of the typesetting layer is declined because native rendering requires one source, not competing authorities.” The intervening sentence about generation from a graph that does not yet carry the objects remains.

The registered conditions of `open:paper:fixed-data-tables` and `open:paper:typed-layer-checks` are obligations of the complete-graph boundary, without new settlement conditions. M070 still forbids settling the former while the latter remains open and rests on it. A relationship is not checked by recording its loss or by registering a rule in a deferred state; permitting either at the complete-graph boundary would require superseding this decision.
