# ADR 041: Compared inherited support in native documents · `rec:adr:041-compared-inherited-support`

**Decision (Statement)** · `dec:notation:compared-inherited-native-support`

Generated native documents load `generated/native-paper-support.tex` before object-bound notation declarations and fragments. Inside `\ExplSyntaxOn` and `\ExplSyntaxOff`, the module emits the byte-checked `\grade`, `\secgrade` and `\gradeword` predecessors from `macros_overlap.tex:267–270`, inputs the unchanged `ftoo_typed_tools.tex`, emits the four M078-compared declarations, then emits comovfield's registered-variance line. The wrapper preserves the expl3 character rules of the compared sources (`documents/paper/main.tex:87–91` and the symbol files' line 2). Only the generated module enters M057's generated inventory and ADR 006 byte gate (`rec:adr:006-byte-gated-generation`); the three compared symbol sources, predecessor file and typed tooling are declared document-receipt inputs. The paper pair keeps its authored-source route and does not load the module. M078 counts declaration sites only in its three named files. Comovfield, willvirtue and gensym enter the M056 native sweep; readout remains outside it until its mathematics-alphabet context is decided. Paper paragraph fragments may contain mathematics only as one of those three compared inherited commands under M055. No notation body receives a shim or checking-effect annotation.

**Reasons (Why)** · `arg:notation:compared-inherited-native-reasons`

M078 binds named paper definitions to checked expressions, and its exact declaration bytes preserve their checking interfaces in the native context. Typed tooling renews three commands that the native preamble does not define: the pinned engine stopped on undefined `\grade`, and the same context loaded after the three predecessor definitions were supplied. The native sweep checks the resulting consuming context; the source comparison and strict screen sweep remain independent.

**Declined (Alternatives)** · `arg:notation:compared-inherited-native-declined`

An AST-rendered shim would add a paper-body authority and omit named effects. Loading all of `macros_overlap.tex` would bring unrelated registries and package dependencies into native documents; loading all symbol and register files would bring unrelated declarations and passage bodies. A local `\symcal` definition adds another body authority, while a document-wide `unicode-math` load with a math face changes every native document, including its calligraphic primitive. The mathematics-context choice requires a separate decision and observed rendering before readout enters a native document or sweep.

**Consequences (Accepted)** · `arg:notation:compared-inherited-native-consequences`

Typed tooling installs 32 document commands, the `granting` environment and the `\g__ftoo_envdepth_int` register, as well as theorem-family begin/end hooks (`ftoo_typed_tools.tex:868–875`), section/subsection and end-document audit hooks (:889–891); it undefines `\normGvec`, `\normGcov`, `\ipGvec`, `\ipGcov` and `\pairing` (:556–560). The section hook fires even on generated starred sections but has no effect while spend logs are empty and no grade is claimed; M056 checks the actual context as content grows. Readout is declared in every native document but use fails because `\symcal` is undefined until its mathematics-alphabet context is decided. Loading typed tooling loads self-description passages 15–17 without invoking or relocating them; passage 19 in `ftoo_registers.tex` is not copied. Those are passage ids in `documents/paper-build/self-description.json:134–176`, and their authored ownership remains under M065. An admitted paper paragraph containing inline mathematics outside the HTML profile remains a registered block gap under record 046 (`rec:adr:046-registered-html-block-gaps`) until that rendering has an emitter for the inline expression.

The manifest catalogue embeds the three M078 sources for admission; the support producer embeds `ftoo_typed_tools.tex` and `macros_overlap.tex` for exact comparison and assembles from the M078 declaration literals exposed by the manifest. Editing either embedded support source invalidates the compiled producer and requires a Rust rebuild; the measured cost depends on the compiler cache and dependency state. `macros_overlap.tex` is the paper's general macro file, so that rebuild cost is accepted rather than hidden. Both embeddings remain until every admission and support-generation entry point receives the same declared source bytes and the document receipt binds them. This explicitly tightens ADR 032:47's conditional removal rule by including the support-generation entry point and its additional inputs. A changed captured input refuses byte comparison, M078 refuses changed declarations and dependencies, and M056 refuses unsupported native TeX context; producer refusals map to located document diagnostics.
