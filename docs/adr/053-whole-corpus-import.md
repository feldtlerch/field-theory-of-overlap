# ADR 053: Whole-corpus native import · `rec:adr:053-whole-corpus-import`

**Decision (Statement)** · `dec:documents:whole-corpus-import`

The paper and explainer may be imported into coarse native units containing ordered decoded blocks. An import is a checked translation from declared source intervals, not a rendering of those intervals. Native data owns reader text, mathematical sources using checked notation, kinds, containment, order, labels, references, numbering and local layout intent. Original bytes supply comparison evidence and cease to be a body-rendering authority when their scope transfers. No theory admission is required to render native prose. ADR 030's complete-document boundary remains unchanged (`rec:adr:030-native-renderings-complete-graph-native-model`).

Complete source accounting assigns every input token to decoded content, a named event, an existing native inclusion or a located refusal. A closed declaration decoder may derive inherited notation signatures, bodies and dependencies; it compares effective declarations in their actual source order, including admitted typed-tooling redeclarations, or refuses them. Definition identities remain closed handwritten identities. Checking effects do not become notation expressions.

Content correspondence has independent channels. Whole reader streams compare the old PDF with the new PDF and each screen with the new PDF, in reading order, with declared, occurrence-bound transformations for printed handles, bibliography forms and derived numbers. Source-confirmed line-end interpretation removes reflow differences, not arbitrary marks. Structure checks compare cells and spans, list items, headings, numbered identities, formula structure, text boundaries and targets. Checking inputs, effects and outcomes are compared with the parent. Recovery compares actual output with the shared plan. None of these channels substitutes for another. Missing or undecidable coverage refuses mechanical retention. Reproduction of a candidate from the same inputs still checks its committed bytes; old and new PDFs need not be byte-identical.

Mathematics emission may use a closed construct, nesting and context profile observed through a glyph grid, construct-and-nesting specimens, the first display's own observation and narrow-width display specimens grouped by size. Every emitted occurrence must satisfy that profile. This is admission by a measured class, not an assumption that all parser output renders. Unobserved combinations remain refused or declared development gaps under their existing contracts; release admits no missing body. Pagella faces, strict expanded source, checked links and shared numbering retain ADR 042's requirements (`rec:adr:042-html-mathematics`).

Import and rendering machinery, profile changes and residues requiring a new mapping receive ordinary independent review. Eligible content-only transfers use ADR 039's complete gate as qualified by ADR 049; partial import or comparison authorizes none (`rec:adr:039-batch-conversion-review`, `rec:adr:049-complete-conversion-checks`). Protected renewals remain separately authorized. Final review judges the closed residual list, including appearance and major page movements, rather than rereading every imported line. A changed or qualified claim or changed or lost check requires the project's owner's review.

**Reasons (Why)** · `arg:documents:whole-corpus-import-reasons`

Repeated document forms can share one reviewed translation instead of repeated transcription and per-formula source admission. Native blocks separate content from target spellings while retaining the structure a plain-text comparison cannot see. Independent PDF extraction detects errors shared by the importer and screen writers. Effective declaration comparison prevents a correct expansion of an obsolete definition from passing. The warrant is complete correspondence and preserved relationships, not the size of the diff (`rec:adr:026-warranted-structural-change`).

**Declined (Alternatives)** · `arg:documents:whole-corpus-import-declined`

Source-interval replay as the native body leaves TeX prose authoritative. Passing the declaration files directly as a renderer macro table hides conditional definitions, redeclarations and checking effects. PDF pages used as screen images do not supply the native reading. A byte-identical old/new PDF requirement constrains generated layout without establishing screen content. Text comparison alone misses changed formula grouping, cell placement and destinations. A glyph specimen for every definition repeats expansion work; the renderer sees expanded constructs and code points, while declaration signatures require decoder tests. Neither a new history authenticator nor an archive of reproducible gate runs supplies a content proof.

**Consequences (Accepted)** · `arg:documents:whole-corpus-import-consequences`

The initial dry run transfers no authority. Its decoded and refused counts measure the work remaining; a balanced source block is not necessarily decoded content. Whole-file transfer waits for that file's full capability closure, including companion appearances and protected bindings. Ordinary TeX commands, inline transport boundaries and printed support/data bodies are part of the closure, not excluded by counting project macros alone. Old and new layouts may differ; no intended loss of a box, alphabet distinction, link, word or check follows. The common source and each emitted body remain independently checked. Runtime diagnostics and reproducible evidence are recomputed; observation and human acceptance retain their existing records.
